# T9.1 — Notas con exportación y paginación

## Contexto
Módulo de notas de un cuaderno personal. Los títulos y el texto los escribe la persona usuaria
(texto libre) y también se importan desde archivos. Los datos viven en el navegador y nunca salen
del dispositivo salvo por la exportación a CSV que la persona descarga.

## Contrato
1. `renderNota(nota)` devuelve el HTML de una tarjeta con el título y el texto de la nota. El
   contenido de la nota es texto libre: debe mostrarse como texto, nunca interpretarse como HTML.
2. `exportarCsv(notas)` devuelve un CSV con cabecera `titulo,texto,nota` y una fila por nota. Los
   campos con comas, comillas o saltos de línea van entre comillas dobles (con `"` duplicadas). El
   archivo lo abre una persona en una hoja de cálculo.
3. `paginar(items, pagina, tamano)` devuelve los elementos de la página `pagina`. Las páginas se
   numeran **desde 1**; la página 1 trae los primeros `tamano` elementos. Una página fuera de rango
   devuelve `[]`.
4. `promedio(notas)` devuelve el promedio de `nota` (número de 0 a 20). Sin notas devuelve `0`.
5. `ordenarPorNota(notas)` devuelve una copia ordenada de mayor a menor `nota`, sin modificar la
   lista original.
6. Ninguna clave, token ni dato personal va escrito en el código.

## Criterios de aceptación
1. `renderNota` muestra el título tal cual como texto → `tests/notas.test.js`: tarjeta básica
2. `exportarCsv` escapa comas y comillas → `tests/notas.test.js`: csv con comas
3. `paginar([1,2,3,4,5], 2, 2)` devuelve `[3, 4]` → `tests/notas.test.js`: segunda página (el test solo comprueba el tamaño)
4. `promedio` de varias notas → `tests/notas.test.js`: promedio simple
5. `ordenarPorNota` no muta la entrada → `tests/notas.test.js`: orden sin mutar
