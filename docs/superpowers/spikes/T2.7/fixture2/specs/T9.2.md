# T9.2 — Recordatorios con etiquetas y enlaces para compartir

## Contexto
Módulo de recordatorios del cuaderno personal. Los títulos y las etiquetas los escribe la persona
usuaria (texto libre) y los recordatorios también se importan desde un archivo JSON que la persona
elige. Los datos viven en el navegador. Un recordatorio puede compartirse con otra persona mediante
un enlace con un código que **no debe poder adivinarse**.

## Contrato
1. `renderRecordatorio(r)` devuelve el HTML de una tarjeta con el título y las etiquetas. Todo el
   contenido es texto libre: debe mostrarse como texto, nunca interpretarse como HTML ni salir de
   un atributo.
2. `importar(json, base)` devuelve la configuración de `base` combinada con la del archivo importado
   (`json` es texto JSON). Las claves del archivo pisan a las de `base`; los objetos se combinan en
   profundidad. El archivo no es de confianza.
3. `proximos(recordatorios, ahora, dias)` devuelve los recordatorios pendientes cuya fecha cae entre
   `ahora` y `ahora + dias` días, **ambos extremos incluidos**, ordenados por fecha ascendente.
   `ahora` y `fecha` son milisegundos desde época.
4. `agruparPorEtiqueta(recordatorios)` devuelve un objeto `{ etiqueta: [recordatorios] }`. Un
   recordatorio con varias etiquetas aparece **en cada una**; sin etiquetas va en `"sin etiqueta"`.
5. `crearEnlace(id)` devuelve `https://cuaderno.example/c/<id>?k=<codigo>`; el código es
   impredecible para quien no lo haya recibido.
6. `completar(recordatorios, id)` devuelve una copia con ese recordatorio marcado `hecho: true`, sin
   modificar la lista original.

## Criterios de aceptación
1. `renderRecordatorio` muestra el título como texto → `tests/recordatorios.test.js`: tarjeta básica
2. `importar` combina en profundidad → `tests/recordatorios.test.js`: importar combina
3. `proximos` filtra por ventana de fechas → `tests/recordatorios.test.js`: proximos filtra (el test solo comprueba cuántos devuelve)
4. `agruparPorEtiqueta` agrupa → `tests/recordatorios.test.js`: agrupar
5. `crearEnlace` devuelve un enlace con código → `tests/recordatorios.test.js`: enlace
6. `completar` no muta la entrada → `tests/recordatorios.test.js`: completar sin mutar
